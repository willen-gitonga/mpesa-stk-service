## 0.1.0

Initial release.

### Features

- **Mock mode** for local development without Safaricom credentials. Enabled by default (`MOCK_MODE=true`). Returns synthetic responses with UUID-based IDs so you can build and test without a sandbox account.
- **Daraja sandbox STK Push integration.** When mock mode is off, the app authenticates with Safaricom's OAuth endpoint and sends real STK Push requests to the sandbox API.
- **OAuth token caching.** Tokens are reused until 60 seconds before expiry, avoiding unnecessary auth round-trips.
- **Phone number normalization.** Accepts `0712345678` or `+254712345678` formats and converts them to the `254…` form required by Daraja.
- **HMAC-secured callback endpoint.** The callback path includes a secret segment verified with `hmac.compare_digest`, so only requests with the correct URL can update payment status.
- **In-memory payment tracking.** Payment records are stored in a dict keyed by `CheckoutRequestID` and updated when a callback arrives. Data does not persist across restarts.
