M-Pesa STK Push Helper is a FastAPI service that sends M-Pesa STK Push payment prompts through Safaricom's Daraja sandbox API and records results when Safaricom calls back. It's for Python developers adding M-Pesa payments to a backend for the first time. It handles the repetitive parts of the Daraja integration so you can focus on your application logic.

## What it does

- **Access-token management.** Fetches and caches Daraja OAuth tokens, refreshing them automatically before they expire.
- **Password and timestamp generation.** Builds the base64-encoded password from your shortcode, passkey, and a timestamp in East Africa Time, as the Daraja API requires.
- **Phone number normalization.** Accepts local (`0712345678`) or international (`+254712345678`) formats and converts them to the `254...` form that Daraja expects.
- **Callback parsing.** Receives Safaricom's asynchronous result on a secret URL path, extracts the receipt number and result code, and updates the payment record.
- **Mock mode.** Returns synthetic responses without contacting Safaricom, so you can develop and test without Daraja credentials.

## Requirements

Python 3.10 or later is required. The project uses Python's `X | None` union-type syntax, which is not available in earlier versions.

## Limitations

Keep these constraints in mind before you start:

- **Sandbox only.** The Daraja base URL (`https://sandbox.safaricom.co.ke`) is hardcoded. There is no production URL option.
- **In-memory storage.** Payment records are held in a Python `dict` inside the application process. All data is lost when the server restarts.
- **No endpoint authentication.** The `/stk-push` and `/payments` routes have no auth layer. Add your own middleware or gateway before exposing the service publicly.
- **Limited phone prefixes.** The phone validation regex accepts numbers starting with `2547` or `2541` only. Other valid Kenyan prefixes (for example `2546`) are rejected.
- **Hardcoded request fields.** `AccountReference` is set to `"DocsDemo"` and `TransactionDesc` to `"Payment"` in every STK push request. These values are not configurable.
