M-Pesa STK Push Helper is a FastAPI service that sends M-Pesa STK Push payment prompts through Safaricom's Daraja sandbox API and records the result when Safaricom calls back. It's for Python developers adding M-Pesa payments to a backend for the first time. It handles the repetitive parts of the Daraja integration so you can focus on your application logic.

## What it does

- **Access tokens.** Caches the Daraja OAuth token and fetches a new one shortly before it expires, so you don't authenticate on every request.
- **Password and timestamp.** Builds the base64-encoded password from your shortcode, passkey and a timestamp in East Africa Time, as Daraja requires.
- **Phone number formats.** Accepts local (`0712345678`) or international (`+254712345678`) numbers and converts them to the `254...` format Daraja expects.
- **Callbacks.** Receives Safaricom's payment result on a secret URL, records the result and receipt number, and ignores duplicate callbacks and callbacks for unknown payments.
- **Mock mode.** Returns realistic responses without contacting Safaricom, so you can try the full flow without a Daraja account.

## Requirements

- Python 3.10 or later.
- For the Daraja sandbox only: a Safaricom Daraja developer account and a public HTTPS tunnel such as ngrok. Mock mode needs neither.

## Limitations

Keep these constraints in mind before you start:

- **Sandbox only.** The Daraja sandbox URL is hardcoded. Going live requires Safaricom's go-live process and a production-ready setup.
- **In-memory storage.** Payment records are kept in memory and are lost when the server restarts.
- **No endpoint authentication.** The `/stk-push` and `/payments` routes have no authentication. Add your own before exposing the service publicly.
- **Fixed request fields.** Every STK Push uses `DocsDemo` as the account reference and `Payment` as the description.
